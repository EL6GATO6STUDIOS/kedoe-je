# Cat Programmer Ai

Cat Programmer Ai, gündelik konuşmaları anlayabilen, kodlama, modelleme, oyun ve analiz sorularını ayırt edip cevaplayabilen basit ama entegre bir yapay zeka sohbet uygulamasıdır.

## Özellikler

- Gündelik ifadeleri anlar ve cevap verir.
- Soru olup olmadığını ayırt eder.
- Analiz (yorumlama) içerikli soruları algılar.
- Kodlama sorularını tanır ve örnek kodlar üretir.
- Basit modelleme sorularına SVG ile cevap verir.
- Oyunlar hakkında genel bilgi ve ipuçları sunar.
- Bilgi tabanı kullanmadan, mesaj içerisindeki anahtar kelimelere göre cevap verir.

## Gereksinimler

- Python 3.7+
- Streamlit

## Kurulum ve Çalıştırma

1. Bu depo içindeki dosyaları indirin.
2. Terminal veya komut istemcisinde dosyanın olduğu klasöre gidin.
3. Gerekli paketleri yükleyin:

```bash
pip install -r requirements.txt
